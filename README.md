# University Management System

A console-based University Management System developed using Java. The application provides basic management of student and teacher information through a menu-driven interface.

## 📌 Project Description

This project demonstrates how Java can be used to build a simple university management application using multiple classes, packages, and a service layer.

The system allows users to add and display student and teacher records.

## ✨ Features

* Add Student
* Display Student
* Add Teacher
* Display Teacher
* Exit the application
* Menu-driven console interface

## 👨‍🎓 Student Information

Each student record contains:

* Student ID
* Student Name
* Roll Number
* CGPA

## 👨‍🏫 Teacher Information

Each teacher record contains:

* Teacher ID
* Teacher Name
* Subject
* Salary

## 🛠️ Technologies Used

* Object-Oriented Programming

## ▶️ How to Run

1. Clone the repository.
2. Open the project in IntelliJ IDEA or another Java IDE.
3. Make sure Java/JDK is installed.
4. Open `UniversityManagementSystem.java`.
5. Run the program.
6. Use the menu to add and display student or teacher information.
